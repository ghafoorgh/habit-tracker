# ایجنت هوشمند واتس‌اپ و اینستاگرام برای املاک

این ایجنت:
- از دیتابیس شما (Excel/CSV) به مالکان در **واتس‌اپ** پیام می‌دهد و می‌پرسد ملکشان را برای **فروش** یا **اجاره** عرضه می‌کنند یا نه
- به پیام‌های واتس‌اپ و **دایرکت اینستاگرام** جواب هوشمند می‌دهد (با هوش مصنوعی Claude)
- جزئیات ملک (متراژ، قیمت، منطقه و...) را از گفتگو درمی‌آورد و وضعیت هر مالک را مشخص می‌کند (فروش / اجاره / تمایل ندارد / لغو / نیاز به شما)
- **هیچ پیامی بدون تأیید شما ارسال نمی‌شود.** هر پیش‌نویس در «صف تأیید» پنل می‌آید و شما می‌توانید ویرایش، تأیید، بازنویسی یا رد کنید

## راه‌اندازی سریع روی کامپیوتر خودتان (ویندوز / مک)

1. Node.js نسخهٔ LTS را از https://nodejs.org نصب کنید.
2. این پوشه را دانلود کنید (در GitHub: Code ← Download ZIP) و از حالت فشرده خارج کنید.
3. **ویندوز:** روی `start.bat` دوبار کلیک کنید. **مک:** روی `start.command` دوبار کلیک کنید.
4. بار اول فایل `.env` باز می‌شود. `ANTHROPIC_API_KEY` و `ADMIN_PASSWORD` را بنویسید، ذخیره کنید و دوباره همان فایل را اجرا کنید.
5. مرورگر پنل را باز می‌کند. در تب «اتصال و دیتابیس» کد QR را با واتس‌اپ گوشی اسکن کنید.

کامپیوتر باید روشن بماند تا ایجنت کار کند. اگر سیستم را خاموش کنید، پیام‌ها در صف می‌مانند و بعد از روشن کردن دوباره ارسال می‌شوند.

## نصب (روش دستی)

نیازمندی‌ها: Node.js 20 یا بالاتر، Google Chrome، و کلید API از Anthropic (https://console.anthropic.com).

```bash
cd property-agent
npm install
cp .env.example .env      # بعد فایل .env را باز کنید و ANTHROPIC_API_KEY و ADMIN_PASSWORD را پر کنید
```

فایل `config/business.md` را با اطلاعات خودتان پر کنید (نام، آژانس، منطقه، شماره تماس، مزیت‌ها). ایجنت فقط از همین اطلاعات استفاده می‌کند و از خودش چیزی نمی‌سازد.

## اجرا

```bash
npm start
```

1. پنل را باز کنید: http://localhost:3000
2. در تب **«اتصال و دیتابیس»** کد QR را با گوشی اسکن کنید (واتس‌اپ ← دستگاه‌های متصل ← اتصال دستگاه). فقط یک بار لازم است.
3. فایل Excel مالکان را وارد کنید. ستون‌ها: `نام`، `شماره` (الزامی)، `آدرس`، `نوع ملک`، `توضیحات`. نمونه: `data/sample-contacts.csv`
   (از خط فرمان هم می‌شود: `npm run import -- ./contacts.xlsx`)
4. «ساخت پیش‌نویس» را بزنید تا ایجنت پیام اول را برای چند مالک بنویسد.
5. در تب **«صف تأیید»** پیام‌ها را بخوانید، اگر لازم است ویرایش کنید و «تأیید و ارسال» را بزنید.
6. وقتی مالک جواب داد، ایجنت پاسخ را می‌نویسد و دوباره در صف تأیید می‌آید.

## پیام‌های گزینه‌ای (انتخابی)

- **پیام اول** همراه یک **نظرسنجی واتس‌اپ** با چهار گزینه ارسال می‌شود: فروش / اجاره / با من تماس بگیرید / تمایل ندارم.
  مالک فقط روی یک گزینه می‌زند و وضعیتش خودکار در پنل ثبت می‌شود. بعد ایجنت پیام بعدی را می‌نویسد (مثلاً تعداد اتاق و قیمت را می‌پرسد) و برای تأیید شما می‌فرستد.
- اگر مالک به‌جای زدن گزینه عدد بنویسد (۱، ۲، ۳ یا ۴)، همان گزینه حساب می‌شود.
- در **پاسخ‌های بعدی**، اگر سؤال جواب‌های مشخصی دارد (مثل تعداد اتاق یا زمان بازدید)، ایجنت خودش گزینه پیشنهاد می‌دهد.
- در **صف تأیید** برای هر پیام **۳ نسخه** نوشته شده. یکی را انتخاب کنید یا متن را ویرایش کنید. متن گزینه‌ها را هم می‌توانید عوض کنید، گزینه اضافه کنید، یا تیک «ارسال با گزینه‌ها» را بردارید تا پیام ساده ارسال شود.
- متن گزینه‌های پیام اول و زبانش (`OUTREACH_LANGUAGE`: English، Persian یا Arabic) در `src/config.js` و `.env` قابل تغییر است.
- واتس‌اپ دکمه (Button) را فقط در API رسمی اجازه می‌دهد. به همین دلیل از **نظرسنجی (Poll)** استفاده شده که روی همهٔ گوشی‌ها کار می‌کند.
- در اینستاگرام، گزینه‌ها به‌صورت **دکمهٔ پاسخ سریع** (Quick Reply) نمایش داده می‌شوند.

## ⚠️ مهم: خطر بن شدن شمارهٔ واتس‌اپ

اتصال واتس‌اپ با کتابخانهٔ غیررسمی `whatsapp-web.js` است (مثل WhatsApp Web). پیام دادن به تعداد زیاد افرادی که شماره شما را ندارند **خلاف قوانین واتس‌اپ است و ممکن است شماره بن شود.** برای کم کردن خطر:

- **از یک شمارهٔ جداگانه استفاده کنید**، نه شمارهٔ اصلی‌تان
- شمارهٔ جدید را چند روز عادی استفاده کنید، بعد با تعداد کم (۱۰ تا ۲۰ در روز) شروع کنید
- محدودیت‌های پیش‌فرض در `.env`: حداکثر ۳۰ پیام اول در روز، ۶۰ تا ۱۸۰ ثانیه فاصله بین پیام‌ها، فقط ساعت ۹ تا ۲۰
- پیام اول کوتاه و شخصی باشد و راه «لغو» داشته باشد. هر کس «لغو» بنویسد دیگر هیچ پیامی دریافت نمی‌کند
- اگر نرخ بلاک شدن بالا رفت، ارسال را متوقف کنید

برای حجم بالا، راه امن **WhatsApp Business API رسمی** است (پیام اول با Template تأییدشده).

## اینستاگرام (اختیاری)

اینستاگرام اجازهٔ پیام اول به افراد را نمی‌دهد؛ ایجنت فقط به **دایرکت‌هایی که برای شما می‌آید** جواب می‌دهد (تا ۲۴ ساعت بعد از آخرین پیام آن شخص).

1. اکانت اینستاگرام را Professional (Business یا Creator) کنید
2. در https://developers.facebook.com یک App بسازید و محصول **Instagram** (API with Instagram Login) را اضافه کنید، دسترسی `instagram_business_manage_messages` را بگیرید و Access Token بسازید
3. سرور باید آدرس عمومی HTTPS داشته باشد (مثلاً روی VPS، یا موقتاً با `cloudflared tunnel` / `ngrok`)
4. در تنظیمات Webhook اپ، آدرس `https://YOUR-DOMAIN/webhooks/instagram` و همان `INSTAGRAM_VERIFY_TOKEN` را وارد کنید و رویداد `messages` را فعال کنید
5. در `.env`: `INSTAGRAM_ENABLED=true` و `INSTAGRAM_ACCESS_TOKEN=...`


## نکات

- فایل `config/business.md` را حتماً پر کنید (نام، آژانس، شمارهٔ RERA، شماره تماس).
- مدل پیش‌فرض `claude-opus-5-5` با `CLAUDE_EFFORT=low` است (برای چت سریع و کم‌هزینه). برای هزینهٔ کمتر می‌توانید `CLAUDE_MODEL=claude-haiku-5-5` بگذارید.
- اگر Chrome پیدا نشد، مسیرش را در `CHROME_PATH` بگذارید.
- برای اینکه همیشه روشن بماند، روی یک VPS با `pm2 start src/index.js --name agent` اجرا کنید.
- پوشهٔ `data/` (دیتابیس و نشست واتس‌اپ) را بک‌آپ بگیرید و هرگز در گیت قرار ندهید.
