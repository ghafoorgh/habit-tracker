# عادت‌ها (Habit Tracker)

یک برنامهٔ سادهٔ ثبت عادت برای آیفون و اندروید، کاملاً فارسی و راست‌به‌چپ، ساخته‌شده با [Expo](https://expo.dev) (SDK 58) و Expo Router.

## امکانات

- **صفحهٔ امروز**: تاریخ شمسی امروز، تعداد عادت‌های انجام‌شده و نوار پیشرفت. هر عادت را با یک لمس تیک بزن.
- **هفتهٔ اخیر**: هفت روز گذشته زیر هر عادت نمایش داده می‌شود. با لمس هر روز می‌توانی آن را ثبت یا لغو کنی.
- **زنجیره‌ها**: تعداد روزهای پشت سر هم برای هر عادت. زنجیره تا پایان روز قطع نمی‌شود.
- **آمار**: زنجیرهٔ فعلی، بهترین زنجیره، درصد انجام در ۳۰ روز اخیر و تقویم ۱۵ هفتهٔ گذشته (هفته از شنبه شروع می‌شود).
- **شخصی‌سازی**: نام، نماد (از جمله 🕌 📿 📖 🫖) و رنگ (فیروزه‌ای، آبی ایرانی، زعفرانی، اناری، پسته‌ای و …).
- تقویم هجری شمسی، اعداد فارسی، فونت وزیرمتن، حالت روشن و تاریک، لرزش هنگام تیک زدن.
- **مشاور هوشمند**: گفت‌وگو با یک مربی عادت (OpenAI) که زنجیره‌ها و آمار خودت را می‌بیند و پیشنهاد عملی می‌دهد.
- عادت‌ها روی خود گوشی ذخیره می‌شوند و به حساب کاربری نیازی نیست. (فقط وقتی از مشاور سؤال می‌کنی، خلاصهٔ عادت‌ها برای پاسخ به سرور فرستاده می‌شود.)

## اجرا روی گوشی

۱. برنامهٔ **Expo Go** را از App Store یا Google Play نصب کن.

۲. روی کامپیوتر (Node نسخهٔ ۲۰ یا بالاتر):

```bash
npm install
npx expo start
```

۳. کد QR را در آیفون با دوربین و در اندروید از داخل Expo Go اسکن کن.

> اگر بار اول صفحه چپ‌به‌راست نمایش داده شد، برنامه را یک بار کامل ببند و دوباره باز کن. چیدمان راست‌به‌چپ از اجرای بعدی اعمال می‌شود.

## مشاور هوشمند (OpenAI)

کلید OpenAI هرگز داخل برنامهٔ موبایل قرار نمی‌گیرد. برنامه به مسیر سروری خودش (`src/app/api/advisor+api.ts`) پیام می‌دهد و فقط سرور کلید را دارد.

**اجرا روی کامپیوتر خودت:** فایل `.env` را در ریشهٔ پروژه بساز (در git ثبت نمی‌شود):

```bash
OPENAI_API_KEY=sk-...
# کد شخصی که بار اول در صفحهٔ مشاور وارد می‌کنی؛ بدون آن سرور به هیچ درخواستی جواب نمی‌دهد
ADVISOR_ACCESS_CODE=یک-رمز-طولانی-و-تصادفی
# اختیاری؛ پیش‌فرض gpt-5-mini
OPENAI_MODEL=gpt-5-mini
```

سپس `npx expo start`. سرور توسعه هم صفحه‌ها و هم مسیر `/api/advisor` را سرو می‌کند.

**انتشار (EAS Hosting):** برای نسخهٔ نصبی، سرور باید روی اینترنت باشد:

```bash
npx expo install react-native-web        # لازم برای خروجی وب/سرور
npx eas-cli@latest env:create --name OPENAI_API_KEY --value sk-... --visibility secret --environment production
npx eas-cli@latest env:create --name ADVISOR_ACCESS_CODE --value ... --visibility secret --environment production
npx expo export --platform web
npx eas-cli@latest deploy --prod
```

آدرسی که `deploy` می‌دهد (مثلاً `https://habit-tracker.expo.app`) را به‌صورت `EXPO_PUBLIC_API_URL` برای build تنظیم کن تا برنامهٔ نصبی به همان سرور وصل شود.

> مسیر `/api/advisor` فقط به درخواست‌هایی جواب می‌دهد که `ADVISOR_ACCESS_CODE` را داشته باشند. این برای نسخهٔ آزمایشی شخصی کافی است؛ برای انتشار عمومی باید ورود کاربر و محدودیت تعداد درخواست اضافه شود. در پنل OpenAI هم سقف هزینهٔ ماهانه بگذار.

## ساخت نسخهٔ نصبی

با [EAS Build](https://docs.expo.dev/build/introduction/) و بدون نیاز به Xcode یا Android Studio:

```bash
npx eas-cli@latest build --platform ios      # یا: --platform android / all
```

شناسهٔ برنامه در `app.json` برابر `com.ghafoorgh.habittracker` است.

## توسعه

npm run typecheck   # بررسی TypeScript

### ساختار پروژه

```
src/
  app/                 صفحه‌ها (Expo Router)
    _layout.tsx        فونت، راست‌به‌چپ و ذخیرهٔ داده
    (tabs)/index.tsx   امروز
    (tabs)/stats.tsx   آمار
    (tabs)/advisor.tsx مشاور هوشمند (گفت‌وگو)
    api/advisor+api.ts مسیر سروری که با OpenAI صحبت می‌کند
    habit/new.tsx      عادت جدید
    habit/[id].tsx     ویرایش / حذف عادت
  components/          HabitRow، HabitForm، Heatmap، Text (فونت وزیرمتن)
  lib/
    jalali.ts          تبدیل تاریخ میلادی به شمسی، نام ماه‌ها و روزها، اعداد فارسی
    dates.ts           توابع کمکی تاریخ
    habits.ts          محاسبهٔ زنجیره و درصد انجام
    store.tsx          وضعیت عادت‌ها و ذخیره در AsyncStorage
    advisor.ts         خلاصهٔ عادت‌ها برای مشاور، اعتبارسنجی و ارسال درخواست
    theme.ts           رنگ‌ها و نمادها
```
